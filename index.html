AlgoLab

recognise · loop design · assemble

From an exercise to a function, one step at a time

An exam exercise is a few sentences of English. Writing the Python goes wrong when you jump straight to code. AlgoLab slows you down: you recognise the parts of the sentence, decide whether there is a loop and design it in words, and only then assemble the function.

Your progress

Three steps for every exercise, in this order

1

Recognise

Read the exercise like a specification.

  • Click a phrase of the exercise, then the component it is: the function, an input, the output, a check…
  • A wrong match gives a hint; after two hints you can ask to be shown.
  • Each match goes into the Components list, with no order yet.
2

Loop?

Design before you code.

  • First question: does something have to be repeated? Sometimes the answer is no.
  • If so, five questions define the loop: over what, where it starts, when it stops, what to remember, what to return. A loop inside a loop gets the same questions.
  • The answers are in words. Every wrong answer explains why.
3

Assemble

Put the function together.

  • Put the lines in order and set each indentation with ← and →.
  • Three lines are distractors: they go against your answers. Leave them out.
  • Once solved, see the finished function, why each distractor was wrong, and the loop running in LoopLab.

The exercises

When you are stuck
  1. Read the exercise again, slowly: every phrase is there for a reason.
  2. Read the explanation of your wrong answer: it says which idea you missed.
  3. Look at your Components list: the code is made of those pieces.
  4. Once solved, watch the loop run in LoopLab.
Good to know
  • Nothing is graded, and no code is run: it is practice.
  • The solution shown is one good way to write each function, not the only one.
  • Your progress is saved in this browser only. Another computer or a private window starts fresh.
